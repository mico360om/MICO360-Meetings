# MICO360 Meetings v1.1.0 — Python edition

> **Note:** This release replaces the previous Electron line. The earlier
> Electron source remains available on the [`electron-legacy`](https://github.com/mico360om/MICO360-Meetings/tree/electron-legacy)
> branch. This new edition uses a different installer, so existing v1.0.x
> auto-updates do not carry over — install the new setup below.

A native **offline** Windows desktop app that turns meeting recordings and
transcripts into professional minutes — nothing leaves your computer.

## Highlights
- 🎙️ **Recording** — microphone, **screen + audio**, camera, and **system/loopback
  audio** ("what you hear") so you can capture online-meeting participants.
- 📝 **Offline transcription** (Whisper) with **Speed/Balanced/Accurate** presets.
- 🧠 **Local AI minutes** (Ollama) — 5 styles, **26 ready prompts in 6 categories**.
- 🗣️ **Offline speaker identification** (Speaker 1/2/3, beta).
- 👁️ **Rendered preview** + export to **DOCX / PDF / TXT / Markdown / HTML**
  with branded company profiles.
- 🕑 Local history & search · 🛟 opt-in crash reporter · ⌨️ keyboard shortcuts.

## Install
Download **MICO360Meetings-Setup.exe** below and run it. The smart installer
sets up Ollama and an AI model automatically (skips anything already installed).
After install, the app is ready offline.

## Requirements
Windows 10/11 · ~150 MB download. Python is bundled. The installer fetches
Ollama + a model on first setup (internet needed once).
