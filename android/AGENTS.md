# MICO360 Meetings for Android

Expo SDK 57 + React Native app (spec: `../docs/superpowers/specs/2026-10-15-android-app-design.md`).
Expo changes every SDK: check the versioned docs at https://docs.expo.dev/versions/v57.0.0/ before using an Expo API.

## Layout

- `src/app/` — Expo Router screens only (`_layout.tsx` defines navigators).
- `src/core/`, `src/data/`, `src/services/` — pure TypeScript, unit-tested with vitest. No React, React Native, Expo or Node imports; no `\p{}` regex classes; `test/purity.test.ts` enforces this.
- `src/native/` — thin adapters to Expo and native modules (exercised on the emulator).
- Desktop text data comes only from `src/core/data/desktop.json`, generated by `tools/export_desktop_data.py`; parity fixtures by `tools/make_parity_fixtures.py`.

## Commands

```bash
npx expo install <package>                    # native/Expo packages (SDK-compatible versions)
npm test                                      # vitest
npm run typecheck                             # tsc --noEmit
powershell -File tools/build-mirror.ps1       # APK build (outside Dropbox)
```

## Rules

- Never run Gradle inside Dropbox: native builds go through `tools/build-mirror.ps1`.
- The native `android/` folder is generated by `expo prebuild` and git-ignored; configure it with `app.config.ts` and `plugins/`.
- No EAS or other Expo cloud services; releases are signed APKs on GitHub Releases.
